# 肤镜 · 家庭皮肤手账交互原型

基于已确认的纸白、墨黑、暖橙视觉方案，面向普通用户与家庭。免注册、免登录；用身体位置整理观察记录。

这是本地交互原型。AI 识别服务与 RK3576 尚未接入，真实导入或拍摄的照片只生成个人观察记录，不返回模拟病名或概率。初次打开的示例影像和示例记录均有明确标记。

## 打开原型

已安装依赖时，在本目录运行：

    npm run dev

打开 http://127.0.0.1:5173/ 。首次安装或复制到其他电脑后，先运行 npm ci。已在 Windows、Node 24.18.0、npm 12.0.1、Microsoft Edge 上验证。

请通过本地服务访问，不要直接双击 index.html。地址绑定到本机回环接口，未开放局域网或发布到外部网站。

生产构建预览：

    npm run build
    npm run preview

构建预览地址为 http://127.0.0.1:4173/ 。浏览器按照“协议、主机、端口”分开保存数据，因此 4173 与 5173 的手账彼此独立。日常体验请固定使用 5173 地址。

## 建议体验顺序

1. 首页拖动人体、切换正背面，点击书签打开这一处的手账。点击身体可确认新位置，左右侧以本人为准。
2. 点击“为这一处复查”，导入 JPG、PNG、WebP，或进入摄像头拍摄。也可不提供照片，仅记录感受。
3. 点选症状、持续时间与变化，进入观察页。照片保存默认不勾选；保存后刷新即可验证实际留存行为。
4. 打开“前后对照”，选择两条记录，体验并排与滑动对照。没有保存照片时，仍可比较文字和症状。
5. 进入复查拍摄，使用已保存照片作为可调叠影参考。新照片仅取自实时画面，叠影不会混入。摄像头拒绝授权时，可切回导入照片。
6. 切换或添加家庭成员，安排复查日期。完成一次新的观察后，对应待办会移除。
7. 在“本地档案”中主动导出 JSON。可单独删除记录中的照片，也可确认删除成员或清空全部手账。

初始对照使用同一张人体部位示意图演示两次记录，不代表真实皮肤变化。需要使用个人照片体验时，从本机导入，系统会将其标记为个人内容。

## 本地保存的边界

- 用户确认的成员、位置、症状、日期、备注和复查计划，保存在当前浏览器的 IndexedDB。
- 临时照片不会自动写入档案。明确勾选后保存最长边不超过 2048 像素的 JPEG 副本；本地重编码不携带原图 EXIF 元数据。
- 输入限 JPEG、PNG、WebP，最大 12 MB、3600 万像素。检查文件类型、后缀、内容签名及实际图像解码。
- 删除照片保留文字；删除成员时删除其关联记录与计划，操作前提示范围。不会删除用户电脑中的原始文件。
- 导出默认不含照片，明确勾选后包含个人照片数据。内置示例图片保留素材路径引用。当前原型未实现导入恢复。
- 无账号与加密访问隔离，家庭成员用于整理记录。清除网站数据、更换浏览器或更换地址可能使原档案无法访问。
- 当前没有外部上传、统计服务或运行时第三方素材请求。摄像头只申请视频，不采集音频。
- 复查提醒在网页内显示，未实现关闭网页后的后台通知。
- 存储事务完成后才显示保存成功。存储失败保留草稿，无法读取的旧数据不会被示例覆盖。支持 Web Locks 的浏览器会串行处理不同标签页的写入；其他页的修改需刷新查看。

## 验证

    npm run test:coverage
    npm run test:e2e
    npm run build

浏览器测试使用已安装的 Edge，无需另行下载浏览器。测试使用独立临时浏览器上下文，不触碰日常浏览器中的手账。

- 19 条领域、存储与文件验证测试。
- 16 条浏览器流程，涵盖真实 3D、家庭归属、留存选择、导出删除、存储失败、拍摄叠影与摄像头生命周期。
- 摄像头自动化使用合成媒体流与权限模拟，未以此替代实体摄像头联调。
- 在启动开发服务后，node _tools/visual-check.mjs 可重新输出页面截图。
- 在启动构建预览服务后，node _tools/production-check.mjs 可检查构建页面与保存流程。

详细结果见 [VALIDATION.md](VALIDATION.md)。artifacts 目录中的截图均使用示例或合成画面，不含真实用户照片。

## 文件结构

| 位置 | 内容 |
|---|---|
| src/App.tsx | 页面流程、草稿保护、持久化事务与弹窗组织 |
| src/components/BodyMap.tsx | Three.js 人体、旋转选点、书签投影与二维降级 |
| src/components/CameraPage.tsx | 拍摄、参考叠影、预览与摄像头释放 |
| src/components/JournalPages.tsx | 首页、导入症状、观察结果、前后对照 |
| src/components/JournalDialogs.tsx | 成员、位置、复查、导出表单 |
| src/components/ManagementPages.tsx | 家庭成员、复查计划、本地档案 |
| src/domain/ | 档案关系、保存规则与明确标注的示例 |
| src/lib/ | IndexedDB、图像输入与日期处理 |
| public/models/ | 本地人体 GLB、许可与来源记录 |
| tests/ | 浏览器验收用例 |
| _tools/ | 人体转换、视觉截图与构建检查工具 |

依赖版本及锁文件均固定。Three.js 独立压缩包约 632 kB，gzip 约 158 kB；人体 GLB 约 488 kB。构建会提示 Three.js 超出默认 500 kB 分包提示线，当前未作为错误隐藏。低性能环境可使用二维视图与文字部位列表。
