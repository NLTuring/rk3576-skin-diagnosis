# 素材来源

人体基础网格来自 [MakeHuman Community](https://github.com/makehumancommunity/makehuman)。

本地文件 makehuman-base.obj 对应仓库中的 makehuman/data/3dobjs/base.obj。该文件头明确声明已于 2020 年 9 月以 CC0 发布；项目 LICENSE.md 的资产部分也明确覆盖基础网格。

本目录保留项目许可说明 makehuman-LICENSE.md、完整资产许可 makehuman-LICENSE-ASSETS.md，以及 sources.json 中的下载地址和 SHA-256。

body-matte.png 是该基础网格的本地静态渲染，arm-reference.png 是用于版面占位的局部视图。两者用于评审布局和材质，不是患者照片、病变照片或模型识别证据。

网格仅使用 body 与眼部参考组进行静态渲染，没有运行或复制 MakeHuman 应用程序逻辑。其余人体交互、资产优化和正式产品模型选型尚未实施。
