# 关键页面视觉稿 V1

日期：2026-10-09

本目录包含五张 1680 × 1120 静态页面设计稿及一张总览。

- 00-关键页面总览.png：五屏总览。
- 01-身体手账首页：3D 身体地图与当前部位手账。
- 02-新检查与症状：照片入口与轻量症状卡。
- 03-本次观察与保存：示例结果及照片留存选择。
- 04-前后变化对照：两次同部位观察。
- 05-复查拍摄引导：历史构图参考。

五个页面均同时提供 PNG 和 SVG。SVG 内嵌渲染素材，文字与布局可继续编辑。界面图不具备可点击、相机采集或识别功能；病种、日期、症状和照片区域均为示例。

完整交互规则见上一层的“02-关键页面与交互说明.md”。

assets 保存人体参考网格、许可、来源记录和静态渲染。_work 中的 Python 文件仅用于生成设计图，不是应用代码。

layout-check.json 记录文字是否超出画布边界；实际业务功能尚未测试。
