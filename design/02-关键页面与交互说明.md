## 2. 首页如何工作

首页保留“纸白＋墨黑＋暖橙”的手账气质，以暖白人体作为立体索引。右侧展示当前选中部位的观察记录，选中态使用暖橙书签与引导线。

| 动作 | 预期反馈与去向 |
|---|---|
| 点击“我 / 妈妈 / 爸爸” | 切换当前成员，地图、记录和提醒一起更新 |
| 点击成员旁的加号 | 打开新成员面板，只需称呼即可开始 |
| 点击身体书签 | 短暂聚焦对应部位，右侧切换到该处手账 |
| 点击模型的空白部位 | 进入新位置确认，显示部位及左右侧，确认后再创建记录 |
| 点击“记录新变化” | 选择或确认部位后，进入页面 02 |
| 点击“为这一处复查” | 先选择导入照片或摄像头；具备历史照片且选择摄像头时进入页面 05 |
| 点击“前后对照” | 选择同一观察条目的两个日期后进入页面 04 |
| 点击“按部位列表查找” | 打开可搜索的文字列表；与模型选择同步 |
| 点击正面、背面或复位 | 改变模型视角，保持当前成员不变 |
| 点击复查提醒中的“改期” | 打开日期选择，只有用户确认后才修改安排 |

首页截图表现的是“已有成员、已有记录、选中一个书签”的常用状态。首次使用时，右侧展示建立成员或开始第一条记录的引导。

模型标记位置是用户记录的定位信息。此轮静态图中的标记用基础模型的部位坐标辅助排布；正式交互需要补充表面定位、遮挡处理、背面选中及左右侧确认。

人体外观作为本轮材质和比例参考，尚未确定为最终人体资产或家庭成员个性化外观。

## 3. 新检查与结果保存

主流程：选择成员与位置 → 提供照片 → 确认本次症状 → 分析或补充信息 → 查看本次观察 → 选择保存内容 → 返回部位手账。

页面 02 将照片与症状放在同一屏。用户切换“导入已有照片 / 摄像头拍摄”时，保留当前成员与部位。输入源发生变化后，旧的质量检测结论失效，不能沿用到新照片。

症状采用点选卡片，补充文字为可选项。已有记录只能作为填写参考；新检查应由用户确认本次状态。

页面 03 将结果组织为四部分：

1. 当前成员、部位、日期与影像，确认记录归属。
2. 疑似方向及仍需确认的信息。
3. 可读的观察依据与下一步指引。
4. 结构化记录的保存操作，以及单独的照片留存选择。

“将本次照片保存在本地手账”默认不勾选。点击“保存本次记录”会保存用户确认的文字与结果；只有勾选后才保留照片副本。保存成功后，返回原部位手账并突出显示新增的日期。

“暂不保存”离开当前结果时，应说明本次未保存内容将被放弃。导入的原始文件仍由用户在原位置管理。

截图中的病种和解释为文案结构示例。没有接入并验证模型时，真实用户图片不能触发这一组预填结果；可以提供手动观察记录入口。

## 4. 对照与复查怎样形成连续体验

### 前后对照

进入页面 04 时先确认同一成员、同一观察条目。日期可以替换，但不能无提示混入其他成员或不相关部位。

默认展示左右并排，提供滑动对照入口。角度差异大时，继续保留并排模式更易理解；无法确认可比性时，不展示精确尺寸、变化百分比或自动改善结论。

症状变化来自用户填写，需与算法得出的影像变化分开说明。此轮两侧影像仅作版面占位，不代表真实病变或改善。

### 复查拍摄

页面 05 只在有历史照片且用户选择摄像头时提供上次构图参考。参考透明度可调，也可一键隐藏。

拍摄后先显示本次原始照片，允许重拍。确认后回到页面 02，补充本次症状。历史照片仅用于取景，不会被混入新照片或当成本次识别输入。

“改用已有照片”直接返回页面 02 的导入入口，保留成员、部位与复查上下文。

## 5. 需要一并实现的状态

| 情况 | 界面应如何处理 |
|---|---|
| 尚无家庭成员 | 直接建立成员，无登录或注册页面 |
| 尚无观察记录 | 提供人体点选与部位列表两种入口 |
| 同一区域已有记录 | 让用户选择继续原条目，或为新问题另建条目 |
| 当前记录未保存时切换成员 | 先保存或放弃当前内容，避免关联错人 |
| 摄像头权限被拒绝 | 说明如何重新授权，并保留照片导入入口 |
| 图片模糊或内容不适用 | 提供重拍、重新选择或补充信息，不能当作成功识别 |
| 检测设备离线或模型未接入 | 用普通语言说明不可分析，保留已保存档案与手动记录 |
| 分析无法确定 | 呈现信息不足与可执行的后续动作，允许保存观察记录 |
| 历史照片未保存 | 回顾已有症状与文字；说明照片不可回看 |
| 只有一次记录 | 引导后续再记录，暂不显示可用的前后影像对照 |
| 没有历史构图参考 | 使用普通拍摄引导，不生成虚构的历史照片 |
| 3D 加载失败或设备性能不足 | 使用二维正反面和部位列表，核心操作仍可完成 |
| 删除照片、记录或成员 | 明确影响范围，确认后执行；不删除用户的源文件 |

免登录意味着成员是记录分组，不构成身份权限隔离。保存说明需与实际部署一致：本地存储具体落在电脑还是 RK3576，仍待后续设备方案确定。

## 6. 视觉和操作细节

- 人体保持静止，旋转和聚焦由操作触发；建议聚焦动效从约 250ms 起验证，并支持减少动态效果。
- 选中书签、主按钮和关键文字使用暖橙；橙色不自动代表病情危险。
- 部位标题与日期建立阅读层次，尽量让照片、感受和下一步在同一视野中可见。
- 小部位先放大再选，常用点击区域以约 44px 为起点验证。
- 摄像头与对照视图使用中性影像背景，真实照片不套暖色滤镜。
- 键盘操作可通过成员列表、部位列表、记录列表完成主要任务。
- 目前仅制作桌面尺寸的静态稿，窄屏布局和真实 3D 性能在可点击原型阶段验证。

## 7. 本轮检查与素材

五张页面已实际渲染为 PNG，并进行了页面视觉检查。浏览器检查未发现文字超出画布边界。结果页的照片保存框为未勾选状态，页面均标注示例身份。

这些检查验证设计图的输出与排版，不代表完成了摄像头、模型、保存、3D 命中或端到端业务测试。

人体基础网格来自 MakeHuman 项目，资产采用 CC0 1.0。素材来源、原始许可和 SHA-256 记录保存在 visuals-v1/assets 中。本轮使用本地静态网格渲染与 SVG 排版，没有调用图像生成 API。

后续可点击原型应优先验证三条路径：新建记录、从部位手账发起复查、在缺少历史照片时继续使用。原型通过这些操作检查后，再接入真实识别与硬件能力。
